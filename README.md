# OpenCircle Messenger

Create me an app for communication where you can DM people or groups, face call people or groups, create groups, send photos, send messages, send voice recordings, send videos, send files, etc. It should run through HTML on any device but specifically chromebooks. People can create group chats, calls, etc and make them private if they need to.  It should actually work. If I need to set up anything like apps, I can only do that on my computer, or "Computer1".
